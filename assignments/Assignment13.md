# Lesson 13: Model Distillation

## Overview
This lesson introduces **model distillation**. In distillation, a smaller student model is trained on outputs generated by a stronger teacher model.  This assignment does **not** train a model. It prepares the dataset a future supervised fine-tuning or distillation run would need.
